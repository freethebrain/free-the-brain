Connect your AI

Free the Brain is an MCP server. Any assistant that speaks the Model Context Protocol can read your registry, stage the next triage chunk, capture tasks from a conversation and append notes. Five minutes, two things to copy.

The one rule

The AI stages. You judge. A connected assistant may read, order, chunk, flag, capture and take notes without asking. It may not change a task's urgency, importance, status, deadline or category on its own — those are your judgments, and the assistant can only record one after you have made it in the conversation. The server enforces this: a write that touches any of those fields without an attestation that a person decided it is refused before it reaches your data, and the refusal is visible in the chat. Suggestions are welcome — ask for "your read" and the assistant returns proposed scores as a proposal object that writes nothing. This is the whole of the agreement, and it holds for every assistant, every host, every time.

What you need

  • The server URL. https://mcp.freethebrain.app/mcp placeholder — the real URL is shown in the app under Settings → Connect your AI
  • Your access token. Generated once in the app under Settings → Connect your AI → New token. Treat it like a password: it lets anyone holding it read your registry. You can revoke it from the same screen at any time. placeholder — until the settings screen ships, the owner sets the token on the server directly
  • A Claude plan that includes custom connectors (Pro, Max, Team or Enterprise), or ChatGPT with developer mode available.

In Claude

  1. Open Claude on the web or desktop. Go to Settings → Connectors and choose Add custom connector.
  2. Name it Free the Brain. Paste the server URL into Remote MCP server URL.
  3. Open Advanced settings and paste your access token as the bearer token. (If your Claude build offers only OAuth sign-in for connectors, the server will ask you to sign in with the same Google account you use for the app instead.)
  4. Save. Start a new chat, open the connectors menu (the + or tools icon by the message box) and switch Free the Brain on.
  5. Try it: type full pass status. You should see how many tasks are judged this week and how many remain, by tier. Then triage 5 — Claude stages the next five, and asks you to judge them.

Claude renders the staged chunk as a small view inside the chat on web and desktop. On the phone apps you get the same chunk as text; the view is not guaranteed there yet.

In ChatGPT

  1. Open ChatGPT. Go to Settings → Connectors. If you do not see a Create button, turn on Developer mode under Settings → Connectors → Advanced first; custom MCP servers need it.
  2. Choose Create. Name: Free the Brain. MCP server URL: the server URL above.
  3. Authentication: choose the bearer-token option and paste your access token. Confirm that you trust the connector.
  4. In a new chat, open the tools menu by the message box and enable Free the Brain (in some builds this is under "More" or "Developer mode").
  5. Try it: full pass status, then capture: book the dentist. The second one writes a new Inbox row with the next free ID — that is the proof the connection works end to end.

If it does not work

  • "Unauthorized" or 401 — the token is missing or wrong. Paste it again without spaces; if in doubt, revoke it in the app and make a new one.
  • The connector saves but the tools never appear — check the URL ends in /mcp, and that the connector is switched on in the chat, not only saved in settings.
  • "Refused: covenant" — the assistant tried to set a triage field without your decision. That is the rule working. Tell the assistant what you decide and it will record that.
  • Anything else: support, with the assistant's name and the exact message.
