What Free the Brain is

A task registry with a strong opinion about how to use it: capture instantly and without ceremony; sort it out later, in small doses, in an order the app works out for you; and let the AI assistant you already use do the reading and staging while you keep every judgment. It grew out of a personal system that ran for months on plain text files, and it still writes those files as its archive.

Questions that come up first

Can I sign up?

Not yet. Version 1 is a single-user app: one account, one registry, its author's. The web app, the Android app and the MCP server are all built so that opening it up later is a matter of accounts, not a rewrite, but that phase has not started. If you would like to be told when it does, send a one-line e-mail to the address above.

Does it work offline?

Yes. The app keeps a local copy of the registry and queues the judgments you make while disconnected; they are sent when you are back online. If the same task was changed in two places, the most recent human action wins.

Where is my data?

On the owner's own Cloudflare account, with a plain-text archive on the owner's Google Drive, and a local copy on your device. Nothing is shared with anyone. The privacy policy lists it all in one table.

How do I connect Claude or ChatGPT?

Follow Connect your AI. It should take under five minutes; if the page makes you guess at a step, that is a bug in the page — please report it.

The AI changed a priority I did not ask for.

It should not be able to. Every write that touches urgency, importance, status, deadline or category is refused by the server unless it carries an attestation that a person made the decision. If you see it happen, that is the most important bug report you can send: include the task ID, the assistant you used, and roughly when.

How do I delete my data?

Ask by e-mail. The database and the archive copy are deleted within 30 days. Uninstalling the app removes the local copy at once.

Something is wrong with the Android app.

Say which phone and Android version, and whether the web app at app.freethebrain.app shows the same problem — the Android app is the web app in a native shell, so that one check halves the search.
